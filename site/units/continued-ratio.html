1-1 連比

把兩個比透過共同橋樑接成 x:y:z

3上 (九上) · N-9-1

若 x:y:z=a:b:c，可設 x=ak, y=bk, z=ck(k≠0)\text{若 } x : y : z = a : b : c \text{，可設 } x = ak,\ y = bk,\ z = ck \quad (k \ne 0)若 x:y:z=a:b:c，可設 x=ak, y=bk, z=ck(k=0)

先觀察

做美味蛋糕時，麵粉、砂糖、雞蛋的比例是 4:2:34 : 2 : 34:2:3。當關係中牽涉到三個或更多數量的相對倍數時，雙變數的比例式就不夠用了，我們需要把多個比透過共同的中介橋樑接合起來，寫成連比 x:y:zx : y : zx:y:z！

若 x:y=2:3x:y = 2:3x:y=2:3 且 y:z=4:5y:z = 4:5y:z=4:5，中間的 yyy 數字不同，該如何透過通分搭起橋樑？

一步一步推導

  1. 連比定義：三個或三個以上同類量之間的倍數關係，記作 a:b:ca : b : ca:b:c。連比不能化為單一的「連比值」，但有「兩兩比值相等」。a:b:ca : b : ca:b:c
  2. 連比求法（找公倍數）：以共同項為基準，取兩式中共同項的最小公倍數進行擴分，再整合成連比。x:y=a:b, y:z=c:d  ⟹  找 lcm(b,c)x:y=a:b,\ y:z=c:d \implies \text{找 }\text{lcm}(b,c)x:y=a:b, y:z=c:d⟹找 lcm(b,c)
  3. 參數設法（王牌技巧）：若 x:y:z=a:b:cx : y : z = a : b : cx:y:z=a:b:c，必設 x=ak,y=bk,z=ckx = ak, y = bk, z = ckx=ak,y=bk,z=ck（k≠0k \ne 0k=0），代入多元代數式中瞬間降為單一參數！x=ak, y=bk, z=ck (k≠0)x=ak,\ y=bk,\ z=ck\ (k\ne 0)x=ak, y=bk, z=ck (k=0)
  4. 反比連比轉化：若 2x=3y=4z2x = 3y = 4z2x=3y=4z，同除以最小公倍數 12，得 x6=y4=z3  ⟹  x:y:z=6:4:3\frac{x}{6} = \frac{y}{4} = \frac{z}{3} \implies x:y:z = 6:4:36x​=4y​=3z​⟹x:y:z=6:4:3！ax=by=cz  ⟹  x:y:z=1a:1b:1cax=by=cz \implies x:y:z = \frac{1}{a}:\frac{1}{b}:\frac{1}{c}ax=by=cz⟹x:y:z=a1​:b1​:c1​
