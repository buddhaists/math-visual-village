2-2 弧與圓周角

圓周角等於所對弧度數的一半、半圓對直角與圓內接四邊形

先觀察

站在劇院舞台的觀眾席，前排中央看到的視角最開闊（圓心角）；如果退到最後排牆邊的任意一個座位（圓周角），你會驚喜地發現：不論你坐在左側、中央還是右側，只要看著同一個舞台寬度，你眼睛張開的視角角度完全一模一樣，且剛好等於圓心角度數的一半！

為什麼「半圓所對的圓周角必定是 90 度直角」？圓內接四邊形的對角有何神奇關係？

一步一步推導

  1. 弧度數與圓心角：圓心角的頂點在圓心，其度數定義為所對弧的度數。一整個圓周為 360°。圓心角=所對弧度數\text{圓心角} = \text{所對弧度數}圓心角=所對弧度數
  2. 圓周角定理：頂點在圓周上、兩邊為圓的弦的角稱為圓周角。圓周角度數等於同弧所對圓心角度數的一半！∠P=12∠AOB=12AB^\angle P = \frac{1}{2}\angle AOB = \frac{1}{2}\widehat{AB}∠P=21​∠AOB=21​AB
  3. 同弧圓周角處處相等：只要對著同一段弧，圓周頂點無論在圓周上怎麼跑，張開的圓周角度數完全不變！∠C1=∠C2=∠C3\angle C_1 = \angle C_2 = \angle C_3∠C1​=∠C2​=∠C3​
  4. 圓內接四邊形對角互補：四邊形四頂點都在同一個圓上時，兩對角所對的弧合起來剛好是一整個圓周（360°），因此對角互補（和為 180°）！∠A+∠C=180∘,∠B+∠D=180∘\angle A + \angle C = 180^\circ,\quad \angle B + \angle D = 180^\circ∠A+∠C=180∘,∠B+∠D=180∘
