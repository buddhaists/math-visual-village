1-2 多項式的加減

P(x)±Q(x): 同類項係數相加減，缺項補零P(x) \pm Q(x):\ \text{同類項係數相加減，缺項補零}P(x)±Q(x): 同類項係數相加減，缺項補零

先觀察

當我們整理零錢時，會把 50 元硬幣疊一起、10 元硬幣疊一起、1 元硬幣疊一起。在代數中，x2x^2x2 項與 x2x^2x2 項相加、常數與常數相加，絕不能混為一談！這就是多項式加減的「同類項合併」法則。

為什麼式子中未知數在分母或根號內時，就不能算是多項式？

一步一步推導

  1. 多項式的定義：由數與文字符號經由加、減、乘運算組成的式子。變數不可在分母、絕對值或根號內。anxn+an−1xn−1+⋯+a1x+a0a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0an​xn+an−1​xn−1+⋯+a1​x+a0​
  2. 次數與排列：非零多項式中變數的最高次方稱為次數（degree）。習慣按次數由大到小寫成降冪排列。deg⁡(3x2−4x+5)=2\deg(3x^2 - 4x + 5) = 2deg(3x2−4x+5)=2
  3. 加減法法則：橫式去括號（減法務必分配變號）或直式按降冪對齊，缺項補 0 後同類項係數相加減。(ax2+bx+c)−(dx2+ex+f)=(a−d)x2+(b−e)x+(c−f)(ax^2+bx+c) - (dx^2+ex+f) = (a-d)x^2 + (b-e)x + (c-f)(ax2+bx+c)−(dx2+ex+f)=(a−d)x2+(b−e)x+(c−f)
  4. 加減次數定理：兩多項式加減後，新多項式的次數小於或等於兩者中原本較高者的次數。deg⁡(A±B)≤max⁡(deg⁡A,deg⁡B)\deg(A \pm B) \le \max(\deg A, \deg B)deg(A±B)≤max(degA,degB)
