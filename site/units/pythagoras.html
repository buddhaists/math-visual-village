2-3 畢氏定理

直角三角形三邊正方形面積與坐標兩點距離

2上 (八上) · S-8-6、G-8-1

a2+b2=c2(∠C=90∘)a^2 + b^2 = c^2\quad (\angle C = 90^\circ)a2+b2=c2(∠C=90∘)

先觀察

古埃及尼羅河每年氾濫沖毀農田邊界，土地測量員用一根打了 12 個等距繩結的繩子拉成 3:4:53 : 4 : 53:4:5 的三角形，就能精確造出直角！兩千多年前畢達哥拉斯證明了：直角三角形兩股平方和，永遠等於斜邊平方！

直角三角形三邊中，哪一條邊永遠最長？坐標平面上兩點之間的距離公式是怎麼用它推出來的？

一步一步推導

  1. 畢氏定理：直角三角形中，兩股長為 a,ba, ba,b，斜邊為 ccc，則 a2+b2=c2a^2 + b^2 = c^2a2+b2=c2。斜邊必為最長邊。a2+b2=c2  ⟹  c=a2+b2a^2 + b^2 = c^2 \implies c = \sqrt{a^2 + b^2}a2+b2=c2⟹c=a2+b2​
  2. 常用畢氏三元整數組：(3, 4, 5)、(5, 12, 13)、(7, 24, 25)、(8, 15, 17)、(9, 40, 41) 及其任意倍數！(3k,4k,5k), (5k,12k,13k)(3k, 4k, 5k),\ (5k, 12k, 13k)(3k,4k,5k), (5k,12k,13k)
  3. 畢氏定理逆定理：若三角形三邊滿足 a2+b2=c2a^2 + b^2 = c^2a2+b2=c2（其中 ccc 為最長邊），則此三角形必為直角三角形，∠C=90∘\angle C = 90^\circ∠C=90∘。a2+b2=c2  ⟺  △ 為直角三角形a^2+b^2=c^2 \iff \triangle\text{ 為直角三角形}a2+b2=c2⟺△ 為直角三角形
  4. 平面兩點距離公式：點 A(x1,y1)A(x_1, y_1)A(x1​,y1​) 與 B(x2,y2)B(x_2, y_2)B(x2​,y2​) 作水平鉛直輔助線構成直角三角形，由畢氏定理推得距離公式！AB‾=(x2−x1)2+(y2−y1)2\overline{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}AB=(x2​−x1​)2+(y2​−y1​)2​
