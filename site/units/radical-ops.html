先觀察

當我們遇到 12+27\sqrt{12} + \sqrt{27}12​+27​ 時，不能直接把裡面加成 39\sqrt{39}39​！就像同類項合併一樣，我們必須先把完全平方數提出來化為「最簡根式」：23+33=532\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}23​+33​=53​。這就是根式運算的優雅規律。

為什麼分母有根號時必須進行「分母有理化」？平方差公式在雙項分母中如何發揮奇效？

一步一步推導

  1. 最簡根式三大準則：(1) 被開方數無完全平方因數；(2) 根號內不含分數或小數；(3) 分母不得含有根號。a2b=ab\sqrt{a^2 b} = a\sqrt{b}a2b​=ab​
  2. 乘除法同根相乘：同次根號相乘除，外面乘外面、裡面乘裡面。a×b=ab\sqrt{a} \times \sqrt{b} = \sqrt{ab}a​×b​=ab​。ma×nb=mnabm\sqrt{a} \times n\sqrt{b} = mn\sqrt{ab}ma​×nb​=mnab​
  3. 加減法同類方根：只有化為最簡根式後「根號內數字完全相同」的方根才能合併係數相加減！23+53=732\sqrt{3} + 5\sqrt{3} = 7\sqrt{3}23​+53​=73​
  4. 平方差有理化：遇到 (a+b)(\sqrt{a}+\sqrt{b})(a​+b​) 分母，同乘共軛式 (a−b)(\sqrt{a}-\sqrt{b})(a​−b​)，利用 (x+y)(x−y)=x2−y2(x+y)(x-y)=x^2-y^2(x+y)(x−y)=x2−y2 徹底消除分母根號！1a+b=a−ba−b\frac{1}{\sqrt{a}+\sqrt{b}} = \frac{\sqrt{a}-\sqrt{b}}{a-b}a​+b​1​=a−ba​−b​​
