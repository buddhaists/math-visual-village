1-2 比例線段

等高三角形面積比與平行線截比例線段性質

3上 (九上) · S-9-3

平行線截比例線段：若 DE‾∥BC‾，則 AD‾DB‾=AE‾EC‾=DE‾BC‾\text{平行線截比例線段：若 } \overline{DE} \parallel \overline{BC} \text{，則 } \frac{\overline{AD}}{\overline{DB}} = \frac{\overline{AE}}{\overline{EC}} = \frac{\overline{DE}}{\overline{BC}}平行線截比例線段：若 DE∥BC，則 DBAD​=ECAE​=BCDE​

先觀察

如果一條直線平行於三角形的底邊，橫腰一切，兩側的腰會被切出什麼比例？古希臘泰利斯（Thales）站在金字塔前，用一根木杖與影子長度的比例測量金字塔的高度，依仗的就是名震千古的平行線截比例線段性質！

為什麼「左上：左下 = 右上：右下」，但中間底邊「短底：長底」卻只能等於「上：全」而不能等於「上：下」？

一步一步推導

  1. 等高三角形面積比：高相同的兩個三角形，面積比等於底邊長度比。△ABD△ACD=BD‾CD‾\frac{\triangle ABD}{\triangle ACD} = \frac{\overline{BD}}{\overline{CD}}△ACD△ABD​=CDBD​
  2. 平行線截比例線段：若 DE‾∥BC‾\overline{DE} \parallel \overline{BC}DE∥BC，則兩側截線成比例：上比下＝上比下、上比全＝上比全。AD‾DB‾=AE‾EC‾,AD‾AB‾=AE‾AC‾\frac{\overline{AD}}{\overline{DB}} = \frac{\overline{AE}}{\overline{EC}},\quad \frac{\overline{AD}}{\overline{AB}} = \frac{\overline{AE}}{\overline{AC}}DBAD​=ECAE​,ABAD​=ACAE​
  3. 底邊比的唯一鐵律：中間兩底邊長度比，只能等於「上比全」！絕不能等於「上比下」！DE‾BC‾=AD‾AB‾=AE‾AC‾\frac{\overline{DE}}{\overline{BC}} = \frac{\overline{AD}}{\overline{AB}} = \frac{\overline{AE}}{\overline{AC}}BCDE​=ABAD​=ACAE​
  4. 逆定理判定平行：若一條直線截三角形兩邊所得線段成比例，則此直線必平行於第三邊！AD‾DB‾=AE‾EC‾  ⟹  DE‾∥BC‾\frac{\overline{AD}}{\overline{DB}} = \frac{\overline{AE}}{\overline{EC}} \implies \overline{DE} \parallel \overline{BC}DBAD​=ECAE​⟹DE∥BC
