3-1 比例式

比與比值、外項積等於內項積與參數設法

1下 (七下) · N-7-9

比例式性質：若 a:b=c:d，則 ad=bc(外項乘積 = 內項乘積)\text{比例式性質：若 } a : b = c : d \text{，則 } ad = bc \quad (\text{外項乘積 } = \text{ 內項乘積})比例式性質：若 a:b=c:d，則 ad=bc(外項乘積 = 內項乘積)

先觀察

沖泡奶茶時，紅茶與鮮奶的完美比例是 3:23 : 23:2。如果今天想泡一大壺給全班喝，用了 600 毫升紅茶，需要加入多少鮮奶才不會走味？這就是比例式在生活中的神奇威力！

若兩個比相等 a:b=c:da:b = c:da:b=c:d，為什麼「外項乘積必定等於內項乘積」？

一步一步推導

  1. 比與比值：a:ba : ba:b 的比值為 ab\frac{a}{b}ba​（前項除以後項）。比值是一個數，沒有單位。a:b=ab(b≠0)a : b = \frac{a}{b}\quad (b\ne 0)a:b=ba​(b=0)
  2. 最簡整數比：前後項互質且皆為整數的比。若有分數或小數，先通分或同乘 10 的次方化簡。0.4:23=25:23=6:10=3:50.4 : \frac{2}{3} = \frac{2}{5} : \frac{2}{3} = 6 : 10 = 3 : 50.4:32​=52​:32​=6:10=3:5
  3. 比例式基本性質：a:b=c:d  ⟺  ab=cd  ⟺  ad=bca:b=c:d \iff \frac{a}{b}=\frac{c}{d} \iff ad=bca:b=c:d⟺ba​=dc​⟺ad=bc（外項乘積等於內項乘積）。a:b=c:d  ⟺  ad=bca:b=c:d \iff ad=bca:b=c:d⟺ad=bc
  4. 參數設法（極重要技巧）：若 x:y=a:bx:y=a:bx:y=a:b，常設 x=ak,y=bkx=ak, y=bkx=ak,y=bk（k≠0k\ne 0k=0），將雙變數化為單一參數！x:y=3:5  ⟹  設 x=3k, y=5k (k≠0)x:y=3:5 \implies \text{設 }x=3k,\ y=5k\ (k\ne 0)x:y=3:5⟹設 x=3k, y=5k (k=0)
