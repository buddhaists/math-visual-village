1-1 乘法公式

切開正方形：和的平方、差的平方與平方差

2上 (八上) · A-8-1

(a±b)2=a2±2ab+b2,(a+b)(a−b)=a2−b2(a\pm b)^2 = a^2 \pm 2ab + b^2,\quad (a+b)(a-b) = a^2 - b^2(a±b)2=a2±2ab+b2,(a+b)(a−b)=a2−b2

先觀察

心算 1032103^21032 或 98×10298 \times 10298×102 時，如果用直式硬乘既耗時又容易算錯。但是古希臘幾何學家把大正方形切成四塊拼圖：一塊 a2a^2a2、兩塊 ababab、一塊 b2b^2b2，發現了威力無窮的乘法公式！

為什麼 (a+b)2(a+b)^2(a+b)2 絕對不等於 a2+b2a^2 + b^2a2+b2？中間遺漏了哪兩塊關鍵面積？

一步一步推導

  1. 和的平方公式：邊長 (a+b)(a+b)(a+b) 的大正方形面積，等於一大一小兩正方形與兩塊長方形的和。(a+b)2=a2+2ab+b2(a+b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2
  2. 差的平方公式：從邊長 aaa 的正方形扣除兩條邊長為 bbb 的長條時，右下角 b2b^2b2 被多扣了一次，必須補回！(a−b)2=a2−2ab+b2(a-b)^2 = a^2 - 2ab + b^2(a−b)2=a2−2ab+b2
  3. 平方差公式：邊長 aaa 的大正方形挖掉邊長 bbb 的小正方形，剪開拼接成長為 (a+b)(a+b)(a+b)、寬為 (a−b)(a-b)(a−b) 的長方形。a2−b2=(a+b)(a−b)a^2 - b^2 = (a+b)(a-b)a2−b2=(a+b)(a−b)
  4. 速算對稱性：遇到兩數相乘，若兩數平均是漂亮整數，必用平方差！例如 102×98=(100+2)(100−2)=10000−4=9996102 \times 98 = (100+2)(100-2) = 10000 - 4 = 9996102×98=(100+2)(100−2)=10000−4=9996。(k+d)(k−d)=k2−d2(k+d)(k-d) = k^2 - d^2(k+d)(k−d)=k2−d2
