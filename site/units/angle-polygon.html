3-1 內角與外角

外角等於兩內對角和、多邊形內角和與繞一圈 360°

2下 (八下) · S-8-1、S-8-2

外角=兩內對角和,內角和=(n−2)×180∘,外角和=360∘\text{外角}=\text{兩內對角和},\quad \text{內角和}=(n-2)\times 180^\circ,\quad \text{外角和}=360^\circ外角=兩內對角和,內角和=(n−2)×180∘,外角和=360∘

先觀察

想像你拿著方向盤沿著一個多邊形跑道走完一整圈回到起點，不論是三角形、五邊形還是百邊形，方向盤轉過的所有外角總和，永遠恰好等於轉滿一整圈的 360 度！而將多邊形切成多個三角形，更揭開了內角和的萬能公式！

為什麼任意凸 nnn 邊形的外角和永遠是 360°，跟它到底有幾條邊完全無關？

一步一步推導

  1. 三角形外角定理：三角形任一外角，等於它兩個不相鄰的內對角之和！∠1=∠A+∠B\angle 1 = \angle A + \angle B∠1=∠A+∠B
  2. 凸 nnn 邊形內角和：從一個頂點出發連對角線，可將 nnn 邊形切分成 (n−2)(n - 2)(n−2) 個三角形。內角和為 (n−2)×180∘(n - 2) \times 180^\circ(n−2)×180∘。∑內角=(n−2)×180∘\sum \text{內角} = (n - 2) \times 180^\circ∑內角=(n−2)×180∘
  3. 任意多邊形外角和：每個頂點取一個外角，順著同方向繞行一圈恰轉了 360°。因此任意凸多邊形外角和恆為 360°！∑外角=360∘ (與邊數 n 無關！)\sum \text{外角} = 360^\circ\ (\text{與邊數 }n\text{ 無關！})∑外角=360∘ (與邊數 n 無關！)
  4. 正多邊形巧算技巧：求正 nnn 邊形內角時，先算外角 360∘n\frac{360^\circ}{n}n360∘​，再用 180∘−外角180^\circ - \text{外角}180∘−外角，遠比帶內角和公式快得多！正 n 邊形內角=180∘−360∘n\text{正 }n\text{ 邊形內角} = 180^\circ - \frac{360^\circ}{n}正 n 邊形內角=180∘−n360∘​
