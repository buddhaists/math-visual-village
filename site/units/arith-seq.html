1-1 等差數列

每一步都加同一個公差 d：走 (n−1) 步到第 n 項

2下 (八下) · N-8-3、N-8-4

an=a1+(n−1)da_n = a_1 + (n - 1)dan​=a1​+(n−1)d

先觀察

從電影院排數、行事曆日期，到高鐵每節車廂編號，生活處處充滿固定步長增加的數字規律。若第一項是 a1a_1a1​，每走一步就加上同一個公差 ddd，那麼要走到第 nnn 項，究竟需要跨出幾步公差？

為什麼第 nnn 項公式中乘上的公差數是 (n−1)(n - 1)(n−1) 步，而不是 nnn 步？

一步一步推導

  1. 數列與項：將一串數字按特定順序排列稱為數列。記作 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，其中 a1a_1a1​ 為首項、ana_nan​ 為第 nnn 項（一般項）。a1, a2, a3, …, ana_1,\ a_2,\ a_3,\ \dots,\ a_na1​, a2​, a3​, …, an​
  2. 公差 ddd 的定義：後項減前項恆等於固定常數 ddd。d>0d > 0d>0 數列遞增，d<0d < 0d<0 數列遞減，d=0d = 0d=0 為常數數列。d=an−an−1=a2−a1d = a_n - a_{n-1} = a_2 - a_1d=an​−an−1​=a2​−a1​
  3. 第 nnn 項公式：從 a1a_1a1​ 出發要走 (n−1)(n - 1)(n−1) 個間隔步幅，因此 an=a1+(n−1)da_n = a_1 + (n - 1)dan​=a1​+(n−1)d。an=a1+(n−1)da_n = a_1 + (n - 1)dan​=a1​+(n−1)d
  4. 等差中項：若 a,b,ca, b, ca,b,c 成等差數列，則中間項 bbb 恰為前後兩項的平均數：b=a+c2b = \frac{a + c}{2}b=2a+c​！b=a+c2  ⟺  2b=a+cb = \frac{a + c}{2} \iff 2b = a + cb=2a+c​⟺2b=a+c
