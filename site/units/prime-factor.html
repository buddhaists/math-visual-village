2-1 質因數分解

倍數判別、質數篩法與標準分解式

1上 (七上) · N-7-1、N-7-2

n=2a×3b×5c×⋯(2,3,5⋯為質數)n = 2^a \times 3^b \times 5^c \times \cdots \quad (2, 3, 5\cdots \text{為質數})n=2a×3b×5c×⋯(2,3,5⋯為質數)

先觀察

就像所有化學物質都是由元素週期表上的原子構成一樣，在乘法世界裡，每個大於 1 的正整數都是由質數這群基本積木相乘而成的！這在數學上稱為算術基本定理。

「1」為什麼被排除在質數之外？如果 1 是質數會發生什麼事？

一步一步推導

  1. 因數與倍數：若整數 aaa 能被整數 bbb 整除（a=b×qa=b\times qa=b×q），則 bbb 是 aaa 的因數，aaa 是 bbb 的倍數。a÷b=q  ⟹  b 是 a 的因數a \div b = q \implies b \text{ 是 } a \text{ 的因數}a÷b=q⟹b 是 a 的因數
  2. 倍數判別法：末位偶數（2的倍數）、數字和為 3的倍數（3的倍數）、末兩位被4整除（4的倍數）、奇數偶數位差為 11的倍數（11的倍數）。各位數字之和為 3 的倍數  ⟺  n 為 3 的倍數\text{各位數字之和為 } 3 \text{ 的倍數} \iff n \text{ 為 } 3 \text{ 的倍數}各位數字之和為 3 的倍數⟺n 為 3 的倍數
  3. 質數與合數：大於 1 的整數中，因數只有 1 與本身的數稱為質數；除了 1 與本身還有其他因數的稱為合數。質數恰有兩個因數：1 與自己\text{質數恰有兩個因數：}1\text{ 與自己}質數恰有兩個因數：1 與自己
  4. 標準分解式：由小到大將質因數以乘方形式排列，任何大於 1 的整數其標準分解式皆唯一確定。360=23×32×5(質因數由小到大排列)360 = 2^3 \times 3^2 \times 5 \quad (\text{質因數由小到大排列})360=23×32×5(質因數由小到大排列)

課綱與應用

會考必定出現倍數判別法或根據標準分解式求因倍數關係的分析題。
