4-2 解一元一次不等式與應用

為什麼乘除負數時，不等號一定要轉向？

1下 (七下) · A-7-8

若 a<b 且 c<0，則 ac>bc(同乘或同除以負數，不等號反向)\text{若 } a < b \text{ 且 } c < 0 \text{，則 } ac > bc \quad (\text{同乘或同除以負數，不等號反向})若 a<b 且 c<0，則 ac>bc(同乘或同除以負數，不等號反向)

先觀察

解不等式的大多數步驟（移項、去括號、去分母）都跟解一元一次方程式一模一樣。但是有一個最致命、最容易摔跤的陷阱：當兩邊同乘或同除以一個負數時，不等號必須立刻調轉方向！

為什麼同乘負數時，大於一定要變成小於？

一步一步推導

  1. 加減運算不變向：不等式兩邊同加或同減一個數，不等號方向不變。a<b  ⟺  a+c<b+ca < b \iff a + c < b + ca<b⟺a+c<b+c。a<b  ⟹  a±c<b±ca < b \implies a \pm c < b \pm ca<b⟹a±c<b±c
  2. 乘除正數不變向：不等式兩邊同乘或同除以一個正數（c>0c > 0c>0），不等號方向不變。a<b, c>0  ⟹  ac<bca < b,\ c > 0 \implies ac < bca<b, c>0⟹ac<bc
  3. 乘除負數必反向：數線上取相反數就像以原點為中心照鏡子，右邊的數翻到左邊反而變得更小！所以 c<0c < 0c<0 時方向反轉。a<b, c<0  ⟹  ac>bca < b,\ c < 0 \implies ac > bca<b, c<0⟹ac>bc
  4. 應用題驗證：解完不等式後，需檢驗解是否符合生活常理（例如人數、件數必須是正整數）。解為 x>3.2, x 為正整數  ⟹  最小值為 4\text{解為 } x > 3.2,\ x\text{ 為正整數} \implies \text{最小值為 } 4解為 x>3.2, x 為正整數⟹最小值為 4
