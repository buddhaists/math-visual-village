3-1 以符號列式與運算

未知數 x 的簡記、代值與同類項化簡

1上 (七上) · A-7-1

ax+bx=(a+b)x,a(bx+c)=abx+acax + bx = \co{(a+b)x},\quad a(bx+c) = \co{abx} + \cb{ac}ax+bx=(a+b)x,a(bx+c)=abx+ac

先觀察

當我們不知道確切數字時，用英文字母 xxx 或 yyy 當作「代表箱子」。箱子裡可以裝任何數字。學會用代數式思考，就能把世間萬物千變萬化的數量關係，寫成簡潔明確的數學語言！

x×xx\times xx×x 與 x+xx + xx+x 有什麼本質上的不同？

一步一步推導

  1. 符號簡記約定：數字與文字相乘，乘號省略且數字寫在文字前方（x×3=3xx\times 3 = 3xx×3=3x）；係數為 1 略寫（1x=x1x = x1x=x）；除法寫成分數。a×x=ax,x÷a=xaa\times x = ax,\quad x\div a = \frac{x}{a}a×x=ax,x÷a=ax​
  2. 同類項合併：含相同文字符號且次數相同的項稱為同類項。同類項的係數可以依分配律直接相加減。3x+5x=(3+5)x=8x3x + 5x = (3+5)x = 8x3x+5x=(3+5)x=8x
  3. 去括號與分配律：括號外有負號時，乘進去每一項都要變號。−(ax−b)=−ax+b-(ax - b) = -ax + b−(ax−b)=−ax+b
  4. 代數式求值：將給定的數代入式中的未知數計算；若代入負數，務必加上括號。x=−2  ⟹  3x2−4x=3(−2)2−4(−2)=12+8=20x = -2 \implies 3x^2 - 4x = 3(-2)^2 - 4(-2) = 12 + 8 = 20x=−2⟹3x2−4x=3(−2)2−4(−2)=12+8=20

課綱與應用
