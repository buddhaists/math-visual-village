3-1a 空間中的線與平面

長方體與正四面體中，直線的平行、相交、垂直與歪斜

3下 (九下) · S-9-12

空間兩直線：相交、平行、或歪斜（不在同一平面）\text{空間兩直線：相交、平行、或歪斜（不在同一平面）}空間兩直線：相交、平行、或歪斜（不在同一平面）

先觀察

在平面幾何中，兩條直線如果不相交，就必定平行。但是當我們跨入真實的三維立體空間時，天花板上由東向西的樑柱，與地面上由南向北的鐵軌，它們既不平行、也永遠不會相交！數學把這種三維空間特有的絕妙關係稱為歪斜（Skew）！

長方體的 12 條稜邊中，任選兩條，有多少對互相是「歪斜線」？如何判斷直線垂直於平面？

一步一步推導

  1. 空間兩直線三種關係：
    1. 相交於一點（共面）
    2. 互相平行（共面）
    3. 歪斜線（不共面、不相交且不平行）！相交,平行,歪斜\text{相交},\quad \text{平行},\quad \text{歪斜}相交,平行,歪斜
  2. 直線與平面垂直：若直線 LLL 垂直於平面 EEE 上的兩條相交直線，則直線 LLL 必垂直於平面 EEE 上經過垂足的任意直線！L⊥L1, L⊥L2  ⟹  L⊥EL \perp L_1,\ L \perp L_2 \implies L \perp EL⊥L1​, L⊥L2​⟹L⊥E
  3. 空間長方體對角線公式：長、寬、高分別為 a,b,ca, b, ca,b,c 的長方體，其內部最長空間對角線長度為 a2+b2+c2\sqrt{a^2 + b^2 + c^2}a2+b2+c2​！D=a2+b2+c2D = \sqrt{a^2 + b^2 + c^2}D=a2+b2+c2​
  4. 兩平面位置關係：在空間中，兩個平面要麼互相平行（如天花板與地板），要麼相交於一條直線（如牆壁交界線）。E1∥E2或兩平面相交於直線 LE_1 \parallel E_2\quad \text{或}\quad \text{兩平面相交於直線 } LE1​∥E2​或兩平面相交於直線 L
