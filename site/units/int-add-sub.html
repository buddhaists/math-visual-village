1-2 整數的加減

同號相加、異號抵消與去括號

1上 (七上) · N-7-3、N-7-4、N-7-5

a−b=a+(−b),−(a−b)=−a+ba - b = a + (\co{-b}),\quad -(\co{a}-\cb{b}) = -\co{a} + \cb{b}a−b=a+(−b),−(a−b)=−a+b

先觀察

想像你在數線上走路：加正數向右走，加負數向左走；而減法就是加上相反數。如果賺了 3 元又賠了 5 元，總結算會是在哪裡？

減去一個負數（如 3−(−5)3 - (-5)3−(−5)），為什麼結果反而變大了？

一步一步推導

  1. 同號數相加：符號相同時，將絕對值相加，並保留原符號。例如 (−3)+(−5)=−(3+5)=−8(-3)+(-5)=-(3+5)=-8(−3)+(−5)=−(3+5)=−8。(−a)+(−b)=−(a+b)(-a) + (-b) = -(a+b)(−a)+(−b)=−(a+b)
  2. 異號數相加：符號相反時，用大絕對值減小絕對值，結果符號取絕對值較大者。a+(−b)=a−b(a>b)a + (-b) = a - b\quad (a > b)a+(−b)=a−b(a>b)
  3. 減法轉加法：減去一個數，等於加上該數的相反數。減負等於加正！a−b=a+(−b),a−(−b)=a+ba - b = a + (-b),\quad a - (-b) = a + ba−b=a+(−b),a−(−b)=a+b
  4. 去括號法則：括號前面是負號時，去掉括號裡面每一項都要變號。−(a+b)=−a−b,−(a−b)=−a+b-(a + b) = -a - b,\quad -(a - b) = -a + b−(a+b)=−a−b,−(a−b)=−a+b

課綱與應用

整數四則混合運算幾乎是每份會考數學科第 1 或第 2 題的送分指標題，務求完全正確。
