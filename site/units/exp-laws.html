2-4 指數律

次方的加減乘：同底數與積的乘方

1上 (七上) · N-7-6、N-7-7

am⋅an=am+n,(am)n=amn,(ab)n=anbna^m\cdot a^n = \co{a^{m+n}},\quad (a^m)^n = \cb{a^{mn}},\quad (ab)^n = \cg{a^n b^n}am⋅an=am+n,(am)n=amn,(ab)n=anbn

先觀察

乘法是加法的快速寫法（3+3+3+3=3×43+3+3+3 = 3\times 43+3+3+3=3×4）；而指數是乘法的快速寫法（3×3×3×3=343\times 3\times 3\times 3 = 3^43×3×3×3=34）。當次方遇到乘法、除法或再乘方時，指數會遵循一套極為優雅的運算規則！

23×242^3\times 2^423×24 為什麼不是底數相乘變成 474^747 或 4124^{12}412？

一步一步推導

  1. 同底相乘指數相加：底數相同的乘方相乘，底數不變，指數相加。am×an=am+na^m\times a^n = a^{m+n}am×an=am+n
  2. 同底相除指數相減：底數相同的乘方相除，底數不變，指數相減。am÷an=am−n(a≠0)a^m\div a^n = a^{m-n}\quad (a\ne 0)am÷an=am−n(a=0)
  3. 乘方再乘方：指數直接相乘。(am)n(a^m)^n(am)n 共有 nnn 組 ama^mam 相乘，累計 m×nm\times nm×n 個 aaa。(am)n=amn(a^m)^n = a^{mn}(am)n=amn
  4. 積的乘方：括號內相乘的各項各自取次方。(ab)n=anbn(ab)^n = a^n b^n(ab)n=anbn。(a×b)n=an×bn(a\times b)^n = a^n\times b^n(a×b)n=an×bn
