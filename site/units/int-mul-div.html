負負得正、四則順序與分配律

1上 (七上) · N-7-3、N-7-4

先觀察

「負負得正」常讓人覺得神秘。想像電影倒帶：一個倒退走（負速度）的人在倒轉播放（負時間）時，畫面看起來就是在往前走！連乘時只要數負號個數：奇數個負為負，偶數個負為正。

為什麼 000 不能當除數？a÷0a\div 0a÷0 究竟代表什麼意思？

一步一步推導

  1. 正負相乘：正負得負、負正得負。例如 3×(−4)=−123\times(-4)=-123×(−4)=−12。a×(−b)=−(ab)a\times(-b) = -(ab)a×(−b)=−(ab)
  2. 負負得正：兩負數相乘，結果為正數。例如 (−3)×(−4)=12(-3)\times(-4)=12(−3)×(−4)=12。(−a)×(−b)=ab(-a)\times(-b) = ab(−a)×(−b)=ab
  3. 除法法則：除以一數等於乘以該數的倒數。同號相除為正，異號相除為負；0 除以任何非零數皆為 0，但 0 不能當除數。a÷(−b)=−(ab),(−a)÷(−b)=aba\div(-b) = -\left(\frac{a}{b}\right),\quad (-a)\div(-b) = \frac{a}{b}a÷(−b)=−(ba​),(−a)÷(−b)=ba​
  4. 乘法分配律：乘法對加法與減法皆具有分配律，善用分配律可以將繁複的四則運算大幅簡化。a(b+c)=ab+ac,(a+b)÷c=a÷c+b÷ca(b+c) = ab+ac,\quad (a+b)\div c = a\div c + b\div ca(b+c)=ab+ac,(a+b)÷c=a÷c+b÷c
