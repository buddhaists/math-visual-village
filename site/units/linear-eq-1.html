先觀察

方程式就像一座平衡的天平。天平兩端同時拿走相同重量、或同時放大相同倍數，天平依然保持完美平衡！利用這個特性，我們就能像剝洋蔥一樣，一步步將未知數 xxx 身邊的數字剝離，找出它的真面目。

移項法則中「加變減、乘變除」，背後真正的原理是什麼？

一步一步推導

  1. 等量公理：等號兩邊同加、同減、同乘、同除以同一個非零數，等式依然成立。A=B  ⟺  A±c=B±c,A×c=B×cA = B \iff A \pm c = B \pm c,\quad A\times c = B\times cA=B⟺A±c=B±c,A×c=B×c
  2. 移項法則：把一項從等號一邊移到另一邊時，運算符號必須改變（加變減、減變加、乘變除）。ax+b=c  ⟹  ax=c−bax + b = c \implies ax = c - bax+b=c⟹ax=c−b
  3. 去括號與化簡：利用分配律展開括號，並將含未知數的項移到左邊、常數項移到右邊整理成 ax=bax = bax=b。ax=b  ⟹  x=ba(a≠0)ax = b \implies x = \frac{b}{a}\quad (a\ne 0)ax=b⟹x=ab​(a=0)
  4. 去分母技巧：方程式兩邊同乘所有分母的最小公倍數，將分數方程式化為整數方程式求解。x2+x3=5→×63x+2x=30\frac{x}{2} + \frac{x}{3} = 5 \xrightarrow{\times 6} 3x + 2x = 302x​+3x​=5×6​3x+2x=30
