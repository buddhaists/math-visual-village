3-4 全等三角形的應用

中垂線到兩端等距、角平分線到兩邊等距與等腰三角形

2下 (八下) · S-8-5、S-8-8

等腰三角形：AB‾=AC‾  ⟺  ∠B=∠C(等邊對等角、等角對等邊)\text{等腰三角形：} \overline{AB} = \overline{AC} \iff \angle B = \angle C \quad (\text{等邊對等角、等角對等邊})等腰三角形：AB=AC⟺∠B=∠C(等邊對等角、等角對等邊)

先觀察

當我們用全等三角形這把鋒利的手術刀切開幾何圖形時，隱藏在圖形深處的對稱秘密紛紛浮現：等腰三角形兩底角必相等、頂角平分線同時是底邊的中垂線；角平分線上每一點到兩邊距離都相等！

什麼是等腰三角形著名的「三線合一」？哪三條線竟然奇蹟般地重合成同一條？

一步一步推導

  1. 等邊對等角：若三角形兩邊相等（等腰），則這兩邊所對的底角必定相等！AB‾=AC‾  ⟹  ∠B=∠C\overline{AB} = \overline{AC} \implies \angle B = \angle CAB=AC⟹∠B=∠C
  2. 等角對等邊：逆定理同樣成立——若一個三角形有兩角相等，則所對的兩邊必定等長！∠B=∠C  ⟹  AB‾=AC‾\angle B = \angle C \implies \overline{AB} = \overline{AC}∠B=∠C⟹AB=AC
  3. 三線合一：等腰三角形頂角的角平分線、底邊的中線、底邊上的高，三者完全重合為同一條線！頂角平分線=底邊中線=底邊高\text{頂角平分線} = \text{底邊中線} = \text{底邊高}頂角平分線=底邊中線=底邊高
  4. 角平分線定理：角平分線上任意一點到角兩邊的距離相等；中垂線上任意一點到兩端點距離相等。P∈平分線  ⟹  距離相等P\in \text{平分線} \implies \text{距離相等}P∈平分線⟹距離相等
