2-1 統計數據的分布

把資料切成四等份：四分位數 Q1,Q2,Q3、四分位距 IQR 與盒狀圖

先觀察

當你拿到全班段考成績時，單看平均數往往看不到「成績是否兩極化」或「大部分同學集中在哪個分數帶」。統計學家約翰·圖基（John Tukey）發明了著名的盒狀圖（Box Plot）：把數據切成四等份，用一個箱子與兩條鬍鬚，一眼看透全班成績的分散與集中分布！

為什麼「四分位距 IQR」比「全距（Max - Min）」更能客觀描述數據的分散程度？它如何免疫極端值的干擾？

一步一步推導

  1. 五數綜合：將數據由小到大排列後，取：最小值（Min）、第一四分位數（Q1Q_1Q1​）、中位數（Q2Q_2Q2​）、第三四分位數（Q3Q_3Q3​）、最大值（Max）。{min⁡,Q1,Q2,Q3,max⁡}\{\min, Q_1, Q_2, Q_3, \max\}{min,Q1​,Q2​,Q3​,max}
  2. 四分位數算法：設有 nnn 筆資料。求 QkQ_kQk​ 時算 n×k4n \times \frac{k}{4}n×4k​。
    • 若為整數，取該項與下一項的平均
    • 若非整數，無條件進位取該整數項！Qk=切分 25%,50%,75%Q_k = \text{切分 } 25\%, 50\%, 75\%Qk​=切分 25%,50%,75%
  3. 四分位距（IQR）：IQR=Q3−Q1\text{IQR} = Q_3 - Q_1IQR=Q3​−Q1​。代表中間 50% 數據的跨度範圍，完全不受極端值影響，最具穩健代表性。IQR=Q3−Q1\text{IQR} = Q_3 - Q_1IQR=Q3​−Q1​
  4. 盒狀圖判讀：四個區間（Min~Q1, Q1~Q2, Q2~Q3, Q3~Max）各自容納了約 25% 的資料筆數！區間越短代表資料越密集！每段均佔約 25% 筆數\text{每段均佔約 25\% 筆數}每段均佔約 25% 筆數
