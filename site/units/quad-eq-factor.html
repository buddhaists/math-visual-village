4-1 因式分解法解一元二次方程

兩數相乘為 0，至少有一個是 0

2上 (八上) · A-8-6、A-8-7

因式分解解方程式：若 A×B=0，則 A=0 或 B=0\text{因式分解解方程式：若 } A \times B = 0 \text{，則 } A = 0 \text{ 或 } B = 0因式分解解方程式：若 A×B=0，則 A=0 或 B=0

先觀察

如果兩個數相乘等於 0，我們能百分之百肯定：這兩數之中至少有一個必須是 0！利用這個看似質樸的「零乘積性質」，只要把二次方程式因式分解成兩個一次式相乘等於 0，二次方程立刻降階成兩個極好解的一元一次方程！

解方程式 x(x−5)=0x(x - 5) = 0x(x−5)=0 時，如果兩邊同時除以 xxx，會犯下什麼不可挽回的致命失根錯誤？

一步一步推導

  1. 一元二次方程式標準式：化簡後形如 ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0（其中 a≠0a \ne 0a=0）。等號右邊必須整理為 0！ax2+bx+c=0 (a≠0)ax^2 + bx + c = 0\ (a\ne 0)ax2+bx+c=0 (a=0)
  2. 零乘積性質：若 A⋅B=0A \cdot B = 0A⋅B=0，則必定 A=0A = 0A=0 或 B=0B = 0B=0。這是因式分解法的核心心臟。(ax+b)(cx+d)=0  ⟹  x=−ba 或 x=−dc(ax+b)(cx+d)=0 \implies x=-\frac{b}{a}\text{ 或 }x=-\frac{d}{c}(ax+b)(cx+d)=0⟹x=−ab​ 或 x=−cd​
  3. 重根現象：當方程式分解為完全平方 (x−k)2=0(x - k)^2 = 0(x−k)2=0 時，兩根相等，稱為重根，必須註明「重根」。(x−k)2=0  ⟹  x=k （重根）(x-k)^2=0 \implies x = k\ \text{（重根）}(x−k)2=0⟹x=k （重根）
  4. 絕不可隨意除以未知數：若未知數可能為 0，方程式兩邊除以未知數會導致「失根」；正確作法一律移項提公因式！x2=kx  ⟹  x2−kx=0  ⟹  x(x−k)=0x^2=kx \implies x^2-kx=0 \implies x(x-k)=0x2=kx⟹x2−kx=0⟹x(x−k)=0
