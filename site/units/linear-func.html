2-1 一次函數及其圖形

對應關係、一次函數 y=ax+b 與常數函數 y=c

2下 (八下) · F-8-1、F-8-2

f(x)=ax+b(a≠0: 一次函數; a=0: 常數函數)f(x) = ax + b\quad (a\ne 0:\ \text{一次函數};\ a=0:\ \text{常數函數})f(x)=ax+b(a=0: 一次函數; a=0: 常數函數)

先觀察

當你按下自動販賣機上的按鍵 xxx，掉下來的飲料 yyy 必定是唯一且明確的——按下紅茶鍵絕不可能同時掉出綠茶跟奶茶，更不能什麼都不掉！萊布尼茲將這種「每一個輸入 xxx，都恰好對應唯一的輸出 yyy」的關係，命名為函數（Function）！

多對一可以是函數嗎？為什麼一對多與一對無絕對不能稱為函數？

一步一步推導

  1. 函數的核心法則：每一個自變數 xxx，都必定有且僅有一個應變數 yyy 與之對應。允許「多對一」，嚴禁「一對多」與「一對無」。x↦f(x)=yx \mapsto f(x) = yx↦f(x)=y
  2. 一次函數：f(x)=ax+bf(x) = ax + bf(x)=ax+b（a≠0a\ne 0a=0）。其圖形為一條不平行於兩坐標軸的斜直線。a>0a>0a>0 往右上斜，a<0a<0a<0 往右下斜。f(x)=ax+b (a≠0)f(x) = ax + b\ (a\ne 0)f(x)=ax+b (a=0)
  3. 常數函數：f(x)=bf(x) = bf(x)=b（a=0a=0a=0）。不論輸入什麼 xxx，輸出永遠恆等於常數 bbb，圖形為水平線（平行 xxx 軸）。f(x)=b (平行 x 軸)f(x) = b\ (\text{平行 }x\text{ 軸})f(x)=b (平行 x 軸)
  4. 鉛直線不是函數：鉛直線 x=cx = cx=c 上有無數個不同的 yyy（一對多），因此鉛直線絕不是函數圖形！x=c 不是函數圖形x = c\ \text{不是函數圖形}x=c 不是函數圖形
