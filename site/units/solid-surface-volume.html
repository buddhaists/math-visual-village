把立體剪開攤平：直角柱、正角錐與直圓錐的表面積與體積

3下 (九下) · S-9-13

V柱=底面積×h,V錐=13底面積×h,S圓錐側=πrRV_{\text{柱}} = \text{底面積}\times h,\quad V_{\text{錐}} = \frac{1}{3}\text{底面積}\times h,\quad S_{\text{圓錐側}} = \pi r RV柱​=底面積×h,V錐​=31​底面積×h,S圓錐側​=πrR

先觀察

當我們剪開飲料紙盒攤平成 2D 平面時，側面積一秒變成了一個大長方形；而若把冰淇淋甜筒（圓錐）側邊剪開攤平，竟然會變成一個優雅的扇形！古希臘阿基米德證明了：同底等高的錐體體積，剛好是柱體體積的 13\frac{1}{3}31​！

圓錐展開後的扇形弧長，為什麼必須恰好等於底面小圓的完整圓周長？

一步一步推導

  1. 柱體體積公式：直角柱（圓柱、三角柱、四角柱）的體積等於底面積乘上柱高！V柱=底面積×hV_{\text{柱}} = \text{底面積} \times hV柱​=底面積×h
  2. 錐體體積公式：角錐與圓錐的體積，永遠是同底等高柱體體積的三分之一（13\frac{1}{3}31​）！V錐=13×底面積×hV_{\text{錐}} = \frac{1}{3} \times \text{底面積} \times hV錐​=31​×底面積×h
  3. 直圓柱表面積：展開後為兩個底面圓與一個長方形（長為底面圓周長 2πr2\pi r2πr，寬為高 hhh）。S圓柱=2πr2+2πrhS_{\text{圓柱}} = 2\pi r^2 + 2\pi r hS圓柱​=2πr2+2πrh
  4. 直圓錐側面積公式：側邊展開為半徑為母線 RRR 的扇形，弧長等於底圓周 2πr2\pi r2πr。側面積 =πrR= \pi r R=πrR！S側=πrR,總表面積=πr2+πrRS_{\text{側}} = \pi r R,\quad \text{總表面積} = \pi r^2 + \pi r RS側​=πrR,總表面積=πr2+πrR
