3-2 十字交乘法因式分解

拆開頭尾、交叉相乘湊出中間一次項

2上 (八上) · A-8-5

x2+(p+q)x+pq=(x+p)(x+q)x^2 + (p+q)x + pq = (x+p)(x+q)x2+(p+q)x+pq=(x+p)(x+q)

先觀察

當面對一個二次三項式如 x2+5x+6x^2 + 5x + 6x2+5x+6，它沒有公因式可提，也不是完全平方式，這時候該怎麼辦？數學家發明了名震天下的十字交乘法：拆開頭、拆開尾、交叉相乘相加，湊出正中間的一次項！

拆尾巴時，如果常數項是「正數」，拆開的兩個數正負號必須如何？如果是「負數」呢？

一步一步推導

  1. 展開原理回顧：(x+p)(x+q)=x2+(p+q)x+pq(x+p)(x+q) = x^2 + (p+q)x + pq(x+p)(x+q)=x2+(p+q)x+pq。中間一次項係數是兩數之和，常數項是兩數之積。(x+p)(x+q)=x2+(p+q)x+pq(x+p)(x+q) = x^2 + (p+q)x + pq(x+p)(x+q)=x2+(p+q)x+pq
  2. 首項係數為 1 的判別：尋找兩整數 p,qp, qp,q，使 p⋅q=cp \cdot q = cp⋅q=c 且 p+q=bp + q = bp+q=b。常數為正同號、常數為負異號！pq=c, p+q=bpq=c,\ p+q=bpq=c, p+q=b
  3. 首項係數不為 1 的進階：若二次項係數為 aaa（如 2x2+7x+32x^2 + 7x + 32x2+7x+3），首項需拆為 a1×a2a_1 \times a_2a1​×a2​，尾項拆為 c1×c2c_1 \times c_2c1​×c2​ 交互試湊。(a1x+c1)(a2x+c2)(a_1 x + c_1)(a_2 x + c_2)(a1​x+c1​)(a2​x+c2​)
  4. 橫寫成因式：十字交乘成功後，由上到下橫著讀取寫入括號！a1xc1 a2xc2  ⟹  (a1x+c1)(a2x+c2)\begin{array}{c} a_1 x \quad c_1 \ a_2 x \quad c_2 \end{array} \implies (a_1 x + c_1)(a_2 x + c_2)a1​xc1​ a2​xc2​​⟹(a1​x+c1​)(a2​x+c2​)
